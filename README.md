## ✦ About NeonChat

NeonChat is a client project developed under **D9 Dev Project**, focused on bringing the NeonChat platform to desktop and mobile environments.

Built with Electron for desktop and Android technologies for mobile, the application brings the NeonChat experience to supported devices.

Whether you're using Windows, Linux, or Android, NeonChat aims to provide a convenient way to access the platform through a dedicated application.

## 🛠️ Installation

### 🪟 Windows

1. Open the [NeonChat releases](../../releases/latest).
2. Download the NeonChat `.exe` installer.
3. Run the installer.
4. Follow the installation instructions.
5. Launch NeonChat.

Windows may display security warnings for unsigned applications. Only run installers you trust and have obtained from the official release page.

### 🐧 Ubuntu / Debian

1. Open the [NeonChat releases](../../releases/latest).
2. Download the `.deb` package.
3. Open a terminal in the directory containing the downloaded file.
4. Run:

```bash
sudo apt install ./neonchat-desktop-linux.deb
```

Replace the example filename with the actual downloaded filename.

After installation, launch NeonChat from your applications menu if the desktop entry is available.

### 🤖 Android

1. Download the [NeonChat Android APK](https://github.com/markneophytousecond/neonchat/releases/download/neonchat-0150-android/Neonchat-Android.apk).
2. Open the downloaded APK on your Android device.
3. If prompted, allow installation from the app you're using to open the APK.
4. Confirm the installation.
5. Open NeonChat.

**Note:** Android may require you to allow installation from unknown sources for the app you're using to open the APK. Only install APKs from sources you trust.

### 🐧 Linux AppImage

1. Download the `.AppImage` file from the [latest release](../../releases/latest).
2. Open a terminal in the download directory.
3. Make the file executable:

```bash
chmod +x NeonChat-0.15.0.AppImage
```

4. Launch the application:

```bash
./NeonChat-0.15.0.AppImage
```

Replace the example filename with the actual downloaded filename.

If the application reports a missing FUSE dependency, install the appropriate compatibility package for your Linux distribution.
